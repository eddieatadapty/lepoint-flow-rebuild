# Le Point Growth Audit

**Live → https://eddieatadapty.github.io/lepoint-flow-rebuild/**

Five ideas to turn more Le Point users into subscribers, each built into a clickable version of Le Point's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on what the ad promised | +10–20% CR to trial |
| 02 | Ask one question and use the answer | +5–10% CR to trial |
| 03 | Put the 14 free days on the paywall | +5–15% CR to trial |
| 04 | Show what the year saves | +10–15% ARPU |
| 05 | Answer ✕ with six months | +5–10% CR from people who close the paywall |

Every price, rating and feature comes from Le Point's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Le Point. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
